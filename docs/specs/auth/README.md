## 1. 개요

1. 로그인은 **카카오 OAuth** 또는 **휴대폰 OTP**.
2. 처음 로그인하면 이름과 휴대폰 인증을 받는다. 둘 다 있어야 매장 기능을 쓸 수 있다.
3. 휴대폰 번호는 초대 수락 시 본인 확인과 계정 중복 방지에 쓴다.
4. 사장님·직원 계정 구분은 없다. 역할은 `Membership`에 있다.

## 2. 범위 / 비목표

| 포함 | 제외 |
| --- | --- |
| 카카오 로그인, 휴대폰 OTP 로그인 | 이메일·비밀번호 로그인 |
| 첫 로그인 프로필 입력 | 회원 탈퇴 (P1) |
| 세션 유지·로그아웃 | 다중 기기 세션 관리 UI |
| 카카오 계정과 휴대폰 계정 병합 | 소셜 계정 여러 개 연결 |

## 3. 회원 상태

| 상태 | 조건 | 접근 |
| --- | --- | --- |
| `NEW` | 로그인했지만 `name` 또는 `phone` 없음 | `/onboarding/profile`만. 나머지 API `403 PROFILE_INCOMPLETE` |
| `READY` | `name`·인증된 `phone` 있음 | 전체 |

상태는 저장하지 않고 `name && phone` 으로 계산한다.

## 4. 흐름

### 4.1 카카오 로그인

1. `/login` → 카카오 동의 → 콜백
2. `kakaoId`로 User 조회. 없으면 생성 (`name` = 카카오 닉네임, 수정 가능)
3. `phone` 없으면 `/onboarding/profile`로 이동해 OTP 인증
4. 인증한 번호를 이미 다른 User가 쓰고 있으면 **병합**: 기존 User에 `kakaoId`를 붙이고, 새로 만든 User는 삭제한다 (Membership이 없으므로 안전)
5. 완료 후 `callbackUrl`로 복귀 (QR 랜딩·초대 링크 복귀용)

### 4.2 휴대폰 OTP 로그인

1. 번호 입력 → 6자리 코드 발송 (유효 3분)
2. 코드 확인 → `phone`으로 User 조회, 없으면 생성
3. `name` 없으면 `/onboarding/profile`

### 4.3 `callbackUrl`

- 같은 출처의 상대 경로만 허용. `/p/`, `/invite/`, `/owner/`, `/me` 로 시작해야 한다. 그 외는 `/`로 바꾼다 (오픈 리다이렉트 방지).

## 5. OTP 규칙

| 항목 | 값 |
| --- | --- |
| 코드 | 6자리 숫자, 서버 난수 |
| 유효 시간 | 180초 |
| 시도 횟수 | 코드당 5회. 초과 시 코드 폐기 |
| 재발송 | 번호당 60초에 1회, 하루 10회 |
| 저장 | 코드 해시만 저장 |
| 번호 형식 | 국내 휴대폰만. E.164(`+8210…`)로 정규화해 저장 |

공급자는 미결정 (인덱스 Q2).

## 6. 세션

- NextAuth v5, JWT 세션. 만료 30일, 접속 시 연장.
- 세션 payload: `userId`만. 역할·매장은 요청마다 DB에서 확인한다 (비활성화 즉시 반영).

## 7. 화면

| URL | 요소 |
| --- | --- |
| `/login` | 워드마크, "카카오로 시작하기", "휴대폰 번호로 시작하기" |
| `/onboarding/profile` | 이름(필수, 1~20자), 휴대폰 OTP(카카오 로그인 시), 개인정보 수집·이용 고지 |

## 8. API

| Method | Endpoint | 설명 |
| --- | --- | --- |
| POST | `/auth/otp/send` | body `{ phone }` |
| POST | `/auth/otp/verify` | body `{ phone, code }`. 로그인 또는 현재 세션에 번호 연결 |
| GET | `/me` | 현재 사용자, 소속 매장 목록 `{ storeId, storeName, role, status }[]` |
| PATCH | `/me` | body `{ name }` |

## 9. 에러 코드

| code | HTTP | 메시지 |
| --- | --- | --- |
| `OTP_INVALID` | 400 | 인증번호가 맞지 않아요. |
| `OTP_EXPIRED` | 410 | 인증번호가 만료됐어요. 다시 받아 주세요. |
| `OTP_TOO_MANY_ATTEMPTS` | 429 | 시도 횟수를 넘었어요. 인증번호를 다시 받아 주세요. |
| `OTP_RESEND_TOO_SOON` | 429 | 잠시 후 다시 요청해 주세요. |
| `PHONE_INVALID` | 400 | 휴대폰 번호를 확인해 주세요. |

## 10. 수용 기준

- [ ] 카카오로 처음 로그인하면 프로필 화면으로 가고, 이름·번호 인증 전에는 매장 API가 `PROFILE_INCOMPLETE`를 준다.
- [ ] 휴대폰으로 가입한 사용자가 나중에 같은 번호로 카카오 로그인하면 하나의 계정이 된다.
- [ ] `callbackUrl=https://evil.com` 은 `/`로 바뀐다.
- [ ] Membership이 비활성화되면 다음 요청부터 해당 매장 API가 `FORBIDDEN`이다 (세션 재발급 불필요).
- [ ] OTP 6번째 시도는 `OTP_TOO_MANY_ATTEMPTS`.
